# Security Policy

## Reporting A Vulnerability

Email security reports privately to [support@sparklaun.ch](mailto:support@sparklaun.ch). Do not open a public issue for a suspected vulnerability.

Include the affected SparkLaunch surface, the observed behavior, the expected behavior, and minimal reproduction steps using synthetic data. Do not include passwords, OAuth codes, access or refresh tokens, confirmation tokens, signed file URLs, private customer data, or other credentials.

SparkLaunch will acknowledge the report, investigate the affected production and package versions, and coordinate remediation and disclosure as appropriate.

## Supported Versions

Security fixes target the current production MCP service and the latest published SparkLaunch plugin package. Reproduce against the latest available version before reporting when it is safe to do so.
